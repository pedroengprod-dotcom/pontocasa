# PontoCasa — MVP v0.1

Protótipo PWA gratuito para validação.

## Funciona nesta fase
- câmera/foto
- GPS real
- raio de 10–200 m
- marcações e histórico
- jornada dia a dia
- cadastro de empregados
- correções auditáveis
- CSV
- cache offline básico

## Limitações
- dados somente no aparelho/browser
- sem login/sincronização entre aparelhos
- horário do servidor ainda não é um servidor real
- sem geocodificação de endereço
- não é REP-P formal

Use somente dados fictícios.

## Publicar no GitHub Pages
1. Faça upload dos arquivos do ZIP na raiz do repositório `pontocasa`.
2. GitHub > Settings > Pages.
3. Build and deployment: Deploy from a branch.
4. Branch: main.
5. Folder: /(root).
6. Save.
7. Aguarde o endereço HTTPS aparecer.
